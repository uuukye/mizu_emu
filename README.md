# mizu_emu
a water simulator (water physics) bc I was bored :P


This is a water simulator that has an isometric 3D view, but coded in 2D. <br>
You can choose between different fluids with different viscosities. The main part of the program I coded was the "flow" of the water. That was really hard, especially that I used an isometric view.

Other features are:
change grid size
build blocks/delete blocks*
absorb fluid


* = this was really hard by the way... coding to alter the structure was really challenging.
